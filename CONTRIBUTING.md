# Contributing

Use Issues for data quality, business problem proposals and showcase submissions. Include the dataset version, relevant table or issue, reproducible evidence and proposed change. Keep application code in your own repository. Do not submit real personal data, credentials, private tests or assessment answers. Contributions of data and documentation are under CC BY 4.0; submit only material you have rights to share. Public showcase inclusion requires consent and maintainer review. Independent solutions do not automatically close business assignments.
